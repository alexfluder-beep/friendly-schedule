# Tests

`sh tests/run-all.sh` runs all screen and reader tests in a headless browser against sample data. `sh tests/run-all.sh t120` runs one.
- t1, t10, t13, t49, t80, t82: core screens, tour card, calendar, admin, small phones.
- t112 to t114, t117 to t119, t121: statistics, analytics cards, driver view, desktop panel, review request, highlights.
- t115: guest review reader. t120: booking e-mails of 10 platforms and review notifications.
Only invented names and numbers belong in these files. Never paste a real guest e-mail or phone.
